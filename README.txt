STUDYSPRINT - DIGITAL MARKETING ASSIGNMENT

FILES
index.html - semantic HTML, SEO title/description, headings and accessible form
styles.css - responsive, mobile-friendly styling
app.js - working task tracker, progress dashboard, Pomodoro focus timer
favicon.svg - local SVG logo

RUN LOCALLY
1. Unzip the downloaded project.
2. Open index.html in a web browser.
3. Try adding, completing and deleting tasks; test timer buttons.

PUBLISH (GITHUB PAGES)
1. Sign in to https://github.com and create a new PUBLIC repository named studysprint.
2. Upload the FOUR website files (index.html, styles.css, app.js, favicon.svg) to the repository ROOT (not inside a folder).
3. Open Settings > Pages, select Deploy from a branch, branch main, folder /(root), and Save.
4. Wait for GitHub to show your public link, usually https://YOUR-USERNAME.github.io/studysprint/ (replace username).
5. Open your link in a private window and test on a phone too.

SEO / ANALYTICS NEXT STEPS
- Register your actual published URL at https://search.google.com/search-console/about
- For a Google Analytics account see https://analytics.google.com . Add your OWN GA4 measurement tag to index.html after creating a web data stream; do not insert someone else's ID.
- Use Lighthouse in Chrome DevTools to capture Performance, Accessibility, Best Practices and SEO audit screenshots.
- Take real screenshots of the published URL, site, and any Analytics/Search Console findings. If just launched, state data are limited instead of inventing numbers.

DATA PRIVACY
Tasks live in localStorage in the browser; no account/server and no cross-device syncing. The timer should remain in an open tab. No sample traffic numbers are claimed.
